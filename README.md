# 作業回数トラッカー（Work Counter App）

## 概要
PythonとTkinterで作成した、作業回数を記録するデスクトップツールです。  
キーボードやボタンで完了回数や修正回数を素早く記録でき、作業を中断せず進捗を管理できます。

## 制作背景
基礎学習の一環として作成。学習用カウンターを出発点に、UIや操作性を改善し、実用的な作業管理ツールに再設計しました。

## 主な機能
- 作業完了回数の記録（+1）
- 修正回数の調整（-1）
- 新しい作業セッションの開始（リセット）
- キーボードショートカット対応
- 常に前面表示で即時操作

## 使用技術
- Python 3
- Tkinter（標準ライブラリ）

## 工夫した点
- クラス設計でUIと処理を分離
- `IntVar` / `StringVar` による状態管理
- キーボード中心の操作設計
- シンプルで分かりやすい画面構成
